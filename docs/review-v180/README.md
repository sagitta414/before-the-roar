# Current-release commentary review

The companion `crew-review.json` contains saved answers from one fixed release, not a live chat. Do not use the older public v66 trial to rate this release.

Ask reviewers who did not build or tune BTR to read each case's supplied observations and both rounds. Do not show them the builder's verdict or ask them to reward the number of agents. Retain every original response, including negative ratings and abstentions.

For each case, independently rate 1–5:

1. Grounding: every factual assertion is supported by the supplied observations.
2. Usefulness: the follow-up teaches something useful beyond the first round.
3. Distinctiveness: the speakers contribute different information or practical actions.
4. Clarity: a football newcomer can understand the explanation.

Quote any unsupported or repeated sentence. Write the single most useful sentence, or state that none added value. Leave a score blank if unable to judge it. Record an anonymous reviewer ID and whether the reviewer helped build BTR.

This is a crew-only diagnostic review. It cannot establish superiority over a single model. For that claim, freeze a single-model answer set using the same evidence and questions, randomize anonymized A/B presentation, and collect ratings before revealing which system produced each answer. Record cost, latency, ties and all failures alongside preference. No independent ratings have been received for this pack.

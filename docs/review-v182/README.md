# Frozen paired commentary review

Open `review.html` locally, or use `/review-v182.html` on the deployed BTR app. Share the HTML or that link with reviewers; do not send `organizer-key.json` before ratings are returned. No reviews have been collected or invented.

This package preserves eight rounds from the v182 development run, including its failures. It does not represent a final-release superiority claim. The final replay-format and scene-specific Guide corrections were made after this run. The runtime source snapshot is preserved in `../proof/v182-source/` and its SHA-256 manifest is in `../proof/v182-frozen-film-results.json`.

Ask at least three people who did not build or tune the application to score grounding, usefulness, role distinctiveness and clarity. Retain ties, negative scores, exact criticism and every export. A reviewer confirmation is self-attestation, not verified independence; the organizer must confirm it.

The crew used sequential calls and could repair rejected prose. The baseline had one call and no repair. The crew ran first, so elapsed time is descriptive, not a controlled latency experiment. Both received the same current evidence and questions; each retained its own previous round. The comparison contains the three shared model roles; deterministic Vector and Check are omitted from the rating cards. Reviewed fallbacks remain in the crew's delivered text. The organizer key records engines and calls.

Three cases were already used in development. The fourth goalkeeper case is additional coverage, not an independent broadcast-video holdout. Read the supplied annotations as the evidence boundary. Do not infer continuous action across the separately generated shots.

Report the actual paired scores, ties and reviewer count before making any quality claim. This small developer-prepared set cannot establish general superiority or replace an unfamiliar-video benchmark.

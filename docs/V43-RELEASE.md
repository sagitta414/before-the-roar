# v43: a conversation that can continue

Scout selects a bounded evidence tool and streams an observation. Guide reads Scout's actual output before replying. Vector contributes a deterministic calculation; Check supplies the claim verdict; Host receives the preceding contributions. Distinct voice instructions change expression without inventing credentials, emotions, results or measurements. A round costs at most four model requests. Follow-ups are explicit, bounded to three rounds, and reference saved server-side contributions. Changed language, perspective, source revision or incompatible video scenes cannot reuse that history.

The Watch panel retains previous rounds, labels reply relationships and shows streaming drafts as drafts. Follow-ups suppress unchanged math and rule cards; another available calculation can add a new quantitative perspective. Cached rounds replay immediately with no fake typing. Reviewed fallbacks remain labeled.

Twenty fixed evaluation cases are declared. The balanced twelve-case run plus one follow-up has a maximum of 64 model requests. Both arms use the same evidence, temperature and writing contracts. A blind human-review export separates grounding, football usefulness, distinct contributions and conversational quality from automated guard acceptance. No quality advantage is assumed.

The viewer-study route compares records alone with records plus saved crew explanations using randomized, balanced order across two scenarios. It collects no names or emails, sends nothing automatically, and exports results only at the participant's choice. No human results are invented.

The demo presentation uses the functioning application's guided tour. Capture provenance identifies sampled browser frames, existing saved model contributions and reviewed notes. The final recording still needs an allowed public video host for hackathon submission.

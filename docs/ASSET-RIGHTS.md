## Submission check

- Use the measured synthetic replay for claims about identity, distance, pass difficulty or speed.
- Describe the cinematic minute as AI-generated companion coverage with manually reviewed observations.
- Keep fictional club names and the “no league affiliation” statement visible.
- Do not package omitted source clips as reusable assets.
- Reconfirm the repository license, font notices and final demonstration soundtrack before Devpost submission.

# Connected match release

Watch, Match Centre and Truth Lab use the authored synthetic sequence, its shared clock, and its evidence revision. The generated 60-second film remains a separate, manually reviewed source; its pixels are not treated as measured match events. Match Centre now places three simultaneous audience readings beside the synthetic pitch and offers direct Watch and Truth Lab handoffs. The three readings use the same reached records but answer different questions: football concept, calculation, and tactical interpretation.

The Watch room can advance a completed synthetic discussion to the next completed event. The server compares the previous cutoff with the new one, exposes a `next_event` angle only when a new event has actually completed, and composes a five-role response from cited records. Scout reports the new action, Guide explains how to inspect it, Vector calculates a reached measurement, Check keeps the causal boundary, and Host synthesizes the before/after change. One Azure selection request chooses the angle; these are not five independent model inferences. No future event is sent to the first round.

The unedited [v81 live receipt](proof/live-next-event-v81.json) records two completed Azure rounds using two model selections. At 67:22 the third pass is not yet available. At 67:26 the reached pass connects Rafael Costa with Theo Brooks; the second round reports its straight-line average speed as 13.1 km/h and Host updates the count from two to three completed passes. The earlier [v80 receipt](proof/live-next-event-v80.json) is retained. One case demonstrates the workflow, not general answer quality or calibrated video tracking.
